# Summary

**NP** (Nondeterministic Polynomial time): The set of decision problems for which a proposed solution can be verified in polynomial time. (Equivalently: problems that can be solved in polynomial time by a nondeterministic Turing machine).

**P** (Polynomial time): The set of decision problems that can be solved in polynomial time.

NP-Complete problem is a problem within NP to which every other NP problem can be translated in polynomial time, meaning a fast solution to just one would automatically provide a fast solution to them all.

NP-Hard problem is a problem to which every problem in NP can be mathematically translated in polynomial time, but unlike NP-Complete problems, it does not actually have to belong to the NP class itself (meaning its solutions might not be verifiable quickly).

P: solved quickly. NP: verified quickly
